# Retina and glaucoma lasers claims reference

Covers the Eye Care retina and glaucoma laser family: Smart 532, Array LaserLink, Vision One, Novus Spectra and the Smart laser indirect ophthalmoscope (LIO). Digital Duet / SLT claims are in a different file and are not repeated here. Check the [regulatory language](../regulatory/retina-and-glaucoma-lasers.md) before reusing any row.

Source materials reviewed for this pass (control IDs and revisions taken from each document's file name and the index; the Array brochure was read in full around the claim):

- **Array LaserLink brochure** - PB-2005744 Rev. B, copyright 2017, 6-page web file in `5 Sales`. The `7 Archive` print copy (2 pages) has the same revision and the same claim wording.
- **Smart 532 brochure** - PB-2007099 Rev. B, copyright 2017 (2-page print file in `5 Sales`; 6-page web copy in `7 Archive`). No references found.
- **Novus Spectra brochure** - PB-1036850 Rev. D, copyright 2010 (8 pages; print and web copies). No references found.
- **SmartLIO brochure** - PB-2008215 Rev. A, copyright 2017 (2-page file in `5 Sales`; 4-page web copy in `7 Archive`). No references found.
- **Retina banner stand** - PB-2006513 Rev. B, 1 page. No references found.
- **Archived, historical** (`7 Archive`; not used for current claims): Vision One brochure PB-2005743 Rev. B (2017) and Retina brochure PB-2007098 Rev. B (2017). No references were found in either. No newer copy of either is on file.
- **Operator manuals** (Smart 532 US and international editions, Array LaserLink Rev. F, Vision One Rev. H, Novus Spectra Rev. F, SmartLIO, LIO Keeler) carry Clinical References / Ophthalmology References lists. They have UM- numbers, not PB numbers, so they cannot be named in "Appears in", and their reference lists are generic treatment-technique literature, not claims about the Lumenis products. They were not turned into rows.

No rows for this product family existed on main or in the unmerged branch, so IDs start at RG-1. Existing rows kept: 0. Marked superseded: 0. New rows: 1.

## Notes and flags

- **Publication check 2026-10-09:** 1 row checked (RG-1). Confirmed 0; still needs review 1; publication not found 0. RG-1: the cited paper (Nagpal 2010, PMID 20216293) was found and its abstract opened, but the abstract does not contain the 60% figure (it gives 1.43 vs 4.53 minutes per sitting, about 68% less) and the laser studied was PASCAL, not Array LaserLink. Full text not accessible.
- **Why the table is short.** Under the [README](README.md) rules, a claim needs a traceable published reference in the same PB-numbered document. Of the PB-numbered documents on file, only the Array LaserLink brochure prints a journal citation.
- **Statements reviewed and left out because they have no reference on file:** the Smart 532 "SmartPulse" duty-cycle and "defined power on the retina" statements, the Novus Spectra and Vision One statements about spot sharpness and low power density at the cornea, the SmartLIO "improved retina visibility" statement and "one LIO for all your retinal care needs" (all marketing or technical statements with no citation). "Introducing the first laser photocoagulator to ophthalmology in 1970" and similar company-history lines in the Novus Spectra and Vision One brochures are corporate history statements without a citation, not clinical claims.
- **Specifications are not claims.** Spot sizes, wavelengths, duty cycles and illumination patch sizes are product facts and are not listed.
- **RG-1 and the brochure's risk text.** The Array brochure states that Array is "contraindicated for eyes with severe media opacities" and lists risks (increased macular edema; bleeding in areas of neovascularization), and refers readers to the operator manual. Any reuse of RG-1 should carry that risk statement; see the regulatory page.
- **Digital Duet / SLT** claims are tracked in [digital-duet.md](digital-duet.md) and are not borrowed here. Never borrow claims from other products.
- **To add rows later,** a PB-numbered piece with a reference list is needed (for example a current Smart 532 or Vision One clinical brochure, or a PB-numbered version of the manuals). Brochure ages should be confirmed first: the Novus Spectra brochure is from 2010, the others from 2017.
- **What was verified.** The claim wording, its asterisk, the footnote text and the page position were read in the extracted brochure text (PB-2005744 Rev. B, web file and archived print copy). Reference lists in the other brochures were searched for and not found. The cited paper itself was not looked up.
