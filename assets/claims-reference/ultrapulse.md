# UltraPulse claims reference

> **Read the regulatory page first.** Check [regulatory language](../regulatory/ultrapulse.md) before reusing any row. The Alpha intended use is general ("surgical or aesthetic applications requiring the ablation, vaporization, excision, incision or coagulation of soft tissue"), and the US and EU manuals are separate market versions. A study result in this file is a published study of fractional CO2 laser treatment. It is not a cleared indication, and in most rows the study did not use the Alpha (see each row's qualifications).
