# OptiLIGHT claims reference

Source materials reviewed for this pass (newest revision on file of each, only PB-numbered controlled documents are named in the table):

- **Deck** - "OptiLight Pitch Deck, Rev A" (PB-00030660, Rev A). The copy on file has 28 slides; the earlier reviews cited 29 slides and "over 40 clinical studies" where the copy on file says "over 20". No newer revision is on file. See the regulatory page, open question 11.
- **Patient brochure** - "OptiLiGHT Patient Trifold B2C" / "OptiLight B2C Brochure US" (PB-00032060, Rev C), copyright 2024, in a 2-page US layout and a 6-page web layout. Page numbers below use the 2-page layout unless stated.
- **B2B brochure** - PB-00029930, Rev C (2023), digital A4 (6 pages) and print (2 pages). Rev A (2021) was not used.
- **Clinical studies book** - PB-00095490, Rev A (2024), 214 pages: p.2 summary with footnoted claims, reproduced papers and a 74-item publication index (pp.209-213).
- **Quick Reference Guide** - PB-00094760, Rev A, 5 pages.
- **Healthy Beautiful Eyes** - PB-00074650, Rev A, 11 pages (patient and practice education).
- **OptiLIGHT for MDs one-sheet** - PB-00095930, revision letter not shown on the copy on file, 2 pages.

Business-plan decks and the clinical-confidence deck cited by the unmerged branch carry no PB number, so they are not cited in the "Appears in" column.
